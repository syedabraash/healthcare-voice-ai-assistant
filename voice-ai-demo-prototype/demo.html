This page is a self-contained mock-up: the transcript is pre-scripted and the roster is hard-coded, so it runs the same every time with no server or phone call involved. It's here to show the intended conversational flow and data model at a glance. The real system — Vapi handling the actual phone call, Claude driving the conversation, and a FastAPI + SQLite backend persisting records — is in the accompanying project files. See README.md in this folder for how the two relate.
